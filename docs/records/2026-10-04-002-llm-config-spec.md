- 缓存身份规则落地点：自动目录名单记录查询时的连接身份（地址、协议、凭证名，不含 Key）；合并规则第 1 步改为"先核对身份再复制"，排除身份不匹配的旧名单；自动更新第 4 步限定失败只能沿用同入口同身份旧名单。
- 请求路由新增快照规则：本次调用及其重试固定用同一份配置，目录刷新不影响正在执行的请求（对齐 1.md"本次调用固定使用这份配置"）。
- 模型能力字段（支持参数、上下文长度、最大输出）允许留空表示未知，不按模型名称猜。

## 二轮修订（同日，修三个规则缺口）

- 凭证身份升级：连接身份＝地址、协议、凭证名＋实际凭证的本地不可逆指纹；凭证名只负责定位，同名引用下换 Key 身份即变、原名单失效。自动目录不存原始 Key，普通日志不输出 Key 或指纹。调用开始时固定生效配置与已读取凭证，本轮重试不重读外部配置或 Key。
- 合并顺序统一为三步：合并厂商连接信息 → 按身份筛选自动名单 → 合并模型信息叠加手动覆盖；基础资料与查询名单分开对待，名单失效不删基础连接信息。验收表首行预期改为"地址用手动值，未覆盖连接字段沿用基础值，原入口自动名单失效"。
- 能力未知不等于不支持：路由只拦已确认不支持的参数，能力未知可发不带可选参数的基础对话；不自动添加未知可选参数，要用先手动配置补确认能力；上下文上限未知不猜测，服务端超限报错时明确提示。
- 验收表新增 2 项待测：同名换 Key 旧名单失效；仅 ID 能力未知仍可基础对话。现共 14 项待测，均未执行。
