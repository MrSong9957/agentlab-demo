## 7. 收尾轮（2026-10-15，同日执行）：取消语义核查＋文案更正＋归因边界

### 7.1 取消语义四问（代码＋S71 定点实证）

1. **Ctrl+C 停止的是什么**：仅**本地等待**（`recv_timeout` 循环返回 Err）。底层 HTTP 请求不被中止——当前实现未做任何中止动作（等待侧不关 socket、不对辅助线程做中断或 join；「ureq 能否被中断」不作为论据，重叠取消轮更正表述）。S71 直接证据：取消后 `/proc/<pid>/task` 线程数＝基线＋1（辅助线程仍在），响应到达（2.5s 延迟 mock）后回落基线。
2. **辅助线程何时结束、迟到结果去向**：`chat_with_body` 返回（服务端响应到达，或 agent 总超时 180s）→`tx.send` 落已弃接收端（闭包已返回，rx 释放）→`let _ =` 丢弃→线程退出。S71 用 2.5s 短延迟证明回收走「响应到达」路径，非 180s 兜底。
3. **连续/重叠取消是否积累**：**会积累**。两项上限分别表述（重叠取消轮更正，此前「有界/不构成泄漏」表述作废）：**单请求存活时间上限**＝agent 总超时 180s（响应到达则更早）；**总并发（被弃辅助线程并存）数量上限＝无**——每次「提交＋取消」一个在途请求即遗留一个辅助线程，180s 窗口内可重复任意多次，存活数随取消次数增长、各自独立回收。S71 串行两轮（每轮回收后再进下一轮）；S72 重叠实测：A 未回收时叠加 B＝基线＋2 并存，A、B 迟到响应到达后双双回落基线。
4. **旧请求结束后是否影响新 turn/会话/界面**：不会——迟到结果只存在于辅助线程内部，无 history/autosave/DriverEvent 通路；turn 线程已先期 Err 返回。S71 断言：两轮被取消回复永不上屏、第三轮正常完成、零复制写入、退出码 0。持久化面：取消轮仅保留已发生记录（本轮 user 消息，006 错误语义既有），无 assistant 回复入史、无工具执行（工具仅在成功解析后执行，本轮已退出）。

## 8. 重叠取消轮（2026-10-15，同日补充）：S72 证据＋资源边界表述修正

### 8.1 S72 重叠取消定点（无缺陷，验证性通过）

夹具＝cancel_session＋可控延迟 mock：A（2.5s 迟到响应**携带 exec tool_calls**）→ A 取消后其辅助线程未结束时立即发起 B（2.5s 迟到纯文本）→ 取消 B → 正常 C。断言全部通过（首跑即绿，未发现缺陷，按目标不扩大修改）：
- 重叠期 `/proc` 线程数＝基线＋2（两个未结束请求的辅助线程并存）；
- A、B 迟到响应先后到达后双双回落基线（重叠不改变回收路径，非 180s 兜底）；
- A 的迟到 tool_calls **不触发工具执行**（屏幕无工具输出 S72-TOOL-LEAK——若迟到结果被错误处理将执行 exec）；
- B 迟到文本不上屏；C 正常完成不受干扰；零复制写入；退出码 0；
- **不入会话历史**：读 auto 会话文件——含 C 回复（正向锚点，防空跑），不含 B 迟到文本、工具批 id（call-s72）、工具输出。

### 8.2 资源边界（两项上限分别表述，更正「有界/不构成泄漏」）

- **单请求存活时间上限**：每个被弃请求的辅助线程 ≤ agent 总超时 180s（`api.rs` `.timeout(180s)`）；响应到达则更早结束。
- **总并发数量上限**：**无**。每次「提交＋取消」一个在途请求即遗留一个辅助线程，180s 窗口内可重复任意多次；存活线程数随重叠取消次数增长、各自独立回收（S72 实测基线＋2）。此前 §7.1-3「临时性积累、有界、不构成泄漏」表述作废（「有界」仅对单线程存活时间成立，对并存数量不成立）；§6 备忘、handoff §28、010 §6、006 扩展段同步更正。

### 8.3 「ureq 无从中断」收窄

代码能证明的事实＝**当前实现未中止底层 HTTP 请求**：等待侧不关闭 socket、不对辅助线程做中断或 join；「ureq 能否被中断」不作为论据。生产注释（tui_host.rs sender 前）与 §7.1-1/010 §6/006 扩展段已按此收窄——注释属生产文件，本轮触发 v11 候选包（v10 冻结不动）：SHA-256＝`04fbfc50cd121619f29a9d0ce5f04f6bf9e4b844e01fb08b82ec6b16ea3f3c45`，`/vault/008-windows-a6-v11/`（5 件套）＋暂存 `/tmp/008-a6/`；独立核验 MANIFEST 1394/1394、主 crate＋conpty_probe 隔离 target-dir `cargo check --locked`、auto_catalog＝git 基线、收窄注释/S72/新文案标记在包。v5–v10 全保留。
