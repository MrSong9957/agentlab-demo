# 008 A3 滚动修复记录（2026-10-14，重开条目闭环）

规格：`docs/specs/008-tui-rendering-port.md` 头部「A3 重开」＋§5-A3（实测结论已回填）。分支 `feat/008-codex-tui-port` @ b0e8d48，未提交。**008 整体仍"实现中"（A6 Windows ConPTY 未闭合）。**

## 1. 根因与证据

- **用户反馈**：TUI 排版正常但无法滚动聊天历史。
- **代码证据（诊断轮）**：`src/tui/src/chat_driver.rs`（008 本地新写驱动）事件分发不完整——①所有 Key 事件只进 `pane.handle_key_event`（composer），从不调用 `transcript_view.handle_key`；②所有 Mouse 事件落入 `_ => {}` 丢弃。鼠标捕获**本已启用**（`tui.rs set_owned_screen→configure_input(capture_mouse=true)`，e2e 原始字节含 `?1000h?1002h?1003h?1006h`）；TranscriptView 的滚动/跟随/限位/锚定机制全部原样在库（`handle_scroll_key`/`scroll`/`jump_to_*`/`is_following`）——断点唯一：驱动分发。
- **母本对照**（/tmp/codex-upstream@97771b1）：`app.rs:989` 对每个事件先走 `handle_owned_transcript_event`；键最终 `transcript_view.handle_key`（PageUp/PageDown(NONE) 一页带一行重叠、JumpTarget 跳转、Esc-to-latest）；鼠标先判 composer 区域（`prepare_composer_mouse`/`handle_composer_mouse`）再 `transcript_view.handle_mouse`（滚轮分数行累积→`scroll`，mouse_scroll_speed=1.0）。
- **次生根因（审查/调试轮发现）**：③驱动丢弃 `Resize` 事件→布局永远停留旧尺寸；④PTY 测试宿主不应答 `ESC[6n`/OSC10/11 查询→resize 后 `get_cursor_position` 读等应答期间吞输入（偶发输入死亡伪影；常见 xterm 系终端通常应答，但用户路径是否受影响取决于所用终端的应答行为——本轮无现场证据，不做绝对结论，见文末收尾更新）。

## 2. 修复（全部在本地新写/测试文件，vendored 零改动——custom_terminal.rs sha256 与 009 迁移态一致，独立审查复核）

`src/tui/src/chat_driver.rs`：
1. `transcript_owns_scroll_key(view, key, turn_running, popup_active)`：PageUp/PageDown（无修饰）、JumpTarget（Ctrl+Home/End、Alt+</>）归 transcript；Esc 仅空闲且 `can_return_to_latest()` 时归（母本 Escape-to-latest），turn 中＝中断（J10）；弹窗激活（`pane.has_active_view()`，对齐母本 `no_modal_or_popup_active`）一律归 composer。范围边界：Ctrl+Space（选择起点）、find 键、pager 专属键位（Up/k、Ctrl+U 等）不路由＝不启用选择/复制/搜索。
2. Key 分支：滚动键先 `transcript.handle_key(key, &cells)`，否则原 composer 路径（输入/排队/命令语义不变）。
3. Mouse 分支：`split_screen_areas`（与 draw 共享推导）判区域——transcript 区仅滚轮进 `transcript.handle_mouse`（点击/拖动不路由）；composer 区 `prepare_composer_mouse`＋`handle_composer_mouse`（母本链路）。
4. `Resize(cols, rows)` → `tui.screen_size_for_event(&TuiEvent::Resize(size))`（母本路径；修复布局冻结）。

测试（`src/app/tests/e2e_acceptance.rs`）：S19–S24＋`long_reply`/`scroll_session`/`screen`/`resize` 辅助＋PTY 终端查询应答器（`answer_terminal_queries`，教训见坑 16/17）。单测（chat_driver::tests）：`scroll_key_routing_contract`、`esc_routes_to_transcript_only_when_idle_and_browsing`（经真实 render 设视口后 scroll 构造浏览态）。
