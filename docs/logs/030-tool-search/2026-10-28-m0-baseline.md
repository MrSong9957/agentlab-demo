## 词法与排序冻结（临时探针，已删除）

探针（直接驱动 bm25 2.3.2，English 默认词法，按语料拟合）观察结果——[原始输出 2026-10-28-m0-lexicon-probe.log](2026-10-28-m0-lexicon-probe.log)：

1. **下划线整体成词**：`send_email` 单 token（不是 send＋email）；准确名查询靠该 token 命中。`searching emails` 词干化后为 `search`＋`email`。
2. **中文同词可命中**：deunicode 把 CJK 音译为 ASCII（`邮件`→`jian` 等），说明含相同中文关键词的条目被同一查询命中（如 `邮件`→`youjian` 条目，分 2.81）；不承诺翻译或跨语种同义。
3. **同分时库内顺序任意且不稳定**：10 个同分候选（0.8735）在正序/倒序目录下 matches() 返回顺序不同（tool_04,02,03… vs tool_01,07,06…）——证实调研结论：必须在**完整正分候选**上按（分数降序, (server_id, raw_tool) 字节升序）二次排序后截断，不能用库的预截断结果补排。
4. 停用词生效（`the email` 与 `email` 同分同序）；零命中返回空（`zzzqqq`）。
5. 命中分数均为正；多词查询按 token 重叠计分。

以上事实固化为 `tests/tool_search.rs` 的固定夹具预期（M1），S04 的冻结名单以此为准。
