## 口径边界

- 空目录不建索引（无可搜索项时不声明搜索工具，§1.2），故其「构建/查询」成本为跳过路径（0），不设建索引阈值。
- 查询档的截断上限为 8（limit 缺省）；2048 档命中 128 项（16 分之一）后截断，覆盖「排序后截断」成本。
- 未测：真实 MCP 服务器目录分布、多服务器聚合构建、S17 上下文效果字节数（M5 单列）。
