## 037 专属结论

- **安装失败传播**（037 §5 场景 2，公共证据任务 B 表 B6）：Dockerfile 中 install.sh URL 改为不可达地址后，下载层 `curl` 退出 6、`&&` 链中止、构建整体退出 1、无镜像产出——失败传播成立。
- **已有目标程序非交互安装**（037 §5 场景 3，公共证据任务 B 表 B7）：预置同名假文件，官方脚本仅设 `CC_SWITCH_INSTALL_DIR`＋`CC_SWITCH_FORCE=1`，无 TTY、stdin 关闭下完成替换（脚本自证 `continuing because CC_SWITCH_FORCE=1`），退出 0，目标变为可运行的 `cc-switch 5.11.3` ELF——非交互替换成立。
- **主动更新后的版本对齐**（公共证据任务 A 表）：重建后 `cc-switch --version`＝5.11.3，与构建窗口内 GitHub latest Release v5.11.3（2026-10-22 发布）一致，符合「与本次构建解析的上游稳定版一致」判定口径。
- 生命周期用例（全新数据卷 B1/B3、停启 B2、缺挂载对照 B5）为 036/037 公共场景，结论见公共证据。
