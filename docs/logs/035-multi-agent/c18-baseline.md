## 口径说明

- 时长＝单次完整根用户轮（派发→终文/收尾）的墙钟；A1/A2 子 Agent 模型响应
  为 mock 即时返回，故时长反映的是**宿主开销上界**而非真实模型并发的端到端。
- 峰值 RSS 为**测试进程** VmHWM 增量（含全部子 Agent 线程栈与分配；子 Agent
  为线程形态，无独立子进程 RSS——A 系列子工具用 update_plan，不派生 exec
  进程）。线程数在收尾时为 3–5（子线程已排空）。
- 磁盘＝单次迭代会话目录（auto-*.jsonl 含全部 Agent 事件）实际字节。
- 请求数按脚本常量断言（子发送 8×315＝2520 次于 A1 全程计数核对）。
- **未覆盖**（规格 §1.8 列出、本轮未测，如实登记）：fork all/none 分形对比、
  消息/续派/中断/清理分项计时、1 千/10 万历史下的事件追加、CPU 利用率、
  客户端/服务器分离开销、真实模型请求数/usage 与费用（费用未测，不写 0 值）。
