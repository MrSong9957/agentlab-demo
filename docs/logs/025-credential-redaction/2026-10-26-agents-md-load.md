# 修复 6：AGENTS.md 引用加载验收（2026-10-26）

方法：本地 mock 模型服务（127.0.0.1:18099，捕获请求体）＋隔离 CLAUDE_CONFIG_DIR ＋假
token/模型名，claude -p 新会话（cwd=/workspace）。共两次有效运行，请求体各 ~58KB。

结果：
- 修复后的引用行（正斜杠路径）确实进入上下文：AGENTS.md 全文在场，其中
  「@`docs/规格文档实战法.md`，详细内容查看文档。」以原文出现 ✓。
- 规范正文未进入上下文：内容探针（「一份说明只讲一个能独立验收的功能」「先预测结果，
  再实际运行」）两次均未命中；裸 @（无反引号）对照实验同样不展开，实验后已还原仓库样式。
- 结论：当前 Claude Code 版本对嵌套 memory 引用（CLAUDE.md→AGENTS.md→实战法）不展开
  正文——第一层（~/.claude/CLAUDE.md→@AGENTS.md）在本会话有展开证据，第二层实测不展开。
  按任务边界不擅自扩展指令加载功能；修复 6 的实际收益＝引用路径由错误的反斜杠改为
  正斜杠（对可识别该语法的工具/未来版本正确），「内容实际进入上下文」不成立，如实定位为
  工具机制限制。

结论修正（2026-10-26 收口二）：
- 「反斜杠路径导致正文未展开」的**原假设未获实测支持**：裸 @（无反引号、正斜杠）对照
  实验同样只出现引用行、不展开正文——未展开与路径形式无关，当前工具不支持该自动展开
  机制本身。正斜杠修正保留（语法正确性/可移植性收益仍在），但其收益不包含"使正文自动
  加载"。
- 配套：AGENTS.md §2 已加明确说明——`@` 引用只带入引用行本身，执行涉及被引用文件的
  任务前须**主动读取**该文件；不宣称正文已自动加载，不扩展外部工具功能。

事故如实记录：第一次运行因全局 settings 的 env 块覆盖 ANTHROPIC_BASE_URL，claude -p 实际
经 open.bigmodel.cn 完成了一次真实调用（"回复 ok"，一次最小请求、费用极小），违反本任务
"不调用真实付费服务"边界；后续改用隔离 CLAUDE_CONFIG_DIR 后的两次运行均零真实调用。
