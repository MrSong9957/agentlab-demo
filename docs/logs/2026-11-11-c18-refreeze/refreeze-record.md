# 034 C18 性能门禁重冻结记录（2026-11-11）

性质：环境漂移重新冻结——非代码劣化。改动仅 `src/app/tests/js_orchestration_perf.rs`
`frozen` 模块阈值常量与注释；测试逻辑、产品代码零变化。

## 重冻结原因

- 2026-10-29 冻结的阈值在本机复跑 3/7 用例失败（`assert_p95` 超阈值）。
- 同机干净树（HEAD，无本轮改动）对照：失败集合与断言位置完全一致——排除代码劣化。
- 采样定位漂移：全部 spawn 路径用例统一 +~330ms 固定开销（cold 13.4→336.9ms、
  terminate 6.3→241.8ms），进程内操作反而略快（append 249→202µs）——漂移在
  worker 子进程 spawn/回收链路的环境因素，非编排逻辑。
- A7 轮已核残留进程为零、宿主负载 ≤1%；本采样运行前复查同样干净。

- 口径变化说明：原冻结阈值按「持续运行实测 ×1.5–2」（当时配额致持续/轻载分离
