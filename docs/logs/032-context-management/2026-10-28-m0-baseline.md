## 环境发现：TCHAT_SANDBOX 泄漏（重要）

首轮基线 `proc_session::pipe_ctrl_c_interrupts_and_terminate_kills_ignoring_process` 确定性失败（3/3 复跑均失败，断言"忽略中断＝仍在运行"实测 Completed/exit_code None）。定位过程：

1. 本轮未改任何代码；029 当天上午 phase0 基线（`docs/logs/029-file-patch/2026-10-28-phase0-baseline.log`）该用例通过。
2. 手动复现 dash `trap '' INT` ＋ 独立进程组 ＋ `killpg(SIGINT)`：进程存活并持续写日志——OS 语义正常。
3. 失败残留目录 `/tmp/tchat-proc-*-ctrlc-term/log` 恒为 5 行（≈start 的 250ms yield），证明循环已运行、trap 已生效，中断后死亡。
4. 根因：交互 shell 环境存在 `TCHAT_SANDBOX=1`（033 沙箱工作遗留）。`proc_session::build_tool_command` 检测到后把全部工具命令经 bwrap 包装执行，宿主侧 `killpg(SIGINT)` 到达的是沙箱外层进程，`trap` 语义在沙箱内失效。

处置：测试与验证命令一律 `env -u TCHAT_SANDBOX` 前缀执行（仓库测试自行管理各自的沙箱环境变量）。该环境条件已记入 `rules/project-lessons.md`（见同日补充）。
