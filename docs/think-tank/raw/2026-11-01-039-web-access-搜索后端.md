# 搜索后端专家

workspace 只读核查：`/workspace/docs/specs/` 现有规格至 038，039 尚未建文件。

**我是谁**：为 terminal-chat 039 设计 web_search 后端与工具契约的调研者。

**离谱目标**：常规是接一家付费 API 或裸爬 DDG；我的目标是零成本、每月 2000+ 次稳定搜索、契约对齐 Claude Code；凭多家官方免费额度轮换、DDG 只做兜底。

**我的方案**：
1. 首发双密钥后端：Tavily（每月重置 1000 credits、免信用卡）＋ Brave（新用户每月 $5 免费额度，约 1000 次；老 2000 次/月计划已停新注册）；Serper 的 2500 次是一次性赠送，不押注。
2. DDG html 端点只当最后兜底：2025 年 SearXNG 社区实测其验证码频发，现成 crate `duckduckgo_search` 已于 2024 年停更，自写解析＋退避，预期会被限流。
3. 契约抄 Claude Code：单 query 必填；`allowed_domains`/`blocked_domains` 二选一（同给即 400）；pi 的 `-` 前缀映射到 blocked；结果默认 8 条、上限 10，每条两行「标题＋URL / 摘要」。
4. SearXNG 不首发：公开实例限流且 JSON 多被禁用，自托管须改 settings.yml 才开 JSON，降级为可选后端。

**成立前提**：能注册到 Tavily/Brave 免费密钥；DDG 兜底偶发失败可接受；不要求 Google 级结果质量。

**验证方法**：以各家官方 pricing 页核对额度；契约逐项对照 Anthropic 官方 web-search-tool 文档；脚本对 DDG 连发 100 次实测封禁率；仓库 `cargo check && cargo test` 全量回归。
