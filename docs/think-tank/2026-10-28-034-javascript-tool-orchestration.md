- 目标：确认真实 JS 异步执行、宿主并发及增量输出的可靠接入，不改变冻结功能、容量或验收条件。
- 输入：[034 规格与计划](../specs/034-javascript-tool-orchestration.md)、固定 rquickjs 0.14.0 官方 API、现有分派/保存/MCP 接口。

## 共识

保留独立 worker、有界 IPC、语言能力限制、堆栈/RLIMIT/墙钟双层限制、4 在途及串行通道、单写者与先存后执行。不能仅凭顶层求值返回认定脚本完成，也不能用逻辑槽数证明共享连接上的真实并发。

## 冲突与裁决

输出游标是运行状态，可靠结果提交是审计边界，须在 M3/M4 对齐；仅针对本项的观察结果和既有提交宿主明确先后，不新增事件类型，不改变 007 其他普通工具保存失败的既有处理。落盘失败仍沿本项关闭及未知结果语义，不恢复活 cell 或重放副作用。

社区提到的 Emscripten/Asyncify 问题与本项目原生 Rust 绑定不同；不据此更换引擎、提高配额或宣称本机已有同类缺陷。
