# 039 Web 工具（web_fetch＋web_search）计划前调研

日期：2026-11-01。目标：给 terminal-chat 的模型新增内置 web_fetch（抓网页转 Markdown）与 web_search（搜索）两个工具，参考 pi 生态成熟实现 pi-web-access，回答选型、后端、接线、安全四个定案问题。

参考实现的完整底层逻辑与证据见[参考实现考古](raw/2026-11-01-039-web-access-参考实现考古.md)。核心事实：pi 上游核心不带 web 工具，成熟方案在扩展 pi-web-access（宿主无关核心＋pi 扩展/MCP 双宿主）。

补充对比：与 Codex 托管实现（openai/codex）的具体差异见 [039 Web 工具 Codex 差异对比](../records/2026-11-01-039-web-access-codex-comparison.md)。

## 共识

- **SSRF 是第一设计约束**：仅 https、私网/环回/链路本地全拒、重定向手动循环逐跳重校验、IP 字面量单独补校验、环境代理默认禁用（旁路解析闸）、5 MiB 流式上限＋总墙钟超时。四位专家与考古在原则上一致。
- **提取链定型**：readability-rs（正文，Mozilla 130 例实测 119）＋htmd（HTML→Markdown，turndown 同源）；html2text/nanohtml2text 只出纯文本，弃。charset 手动四级解码（BOM→响应头→meta→chardetng）。
- **契约对齐 Claude Code**：单 query 必填、`allowed_domains`/`blocked_domains` 二选一、默认 8 条上限 10；pi 的 `-` 前缀 deny 语法映射到 blocked。
- **接线走既有同门模式**：prompt.rs 定义＋turn.rs 分派分支＋web_access.rs 单文件执行＋tui_host.rs 渲染分支；003 码点截断＋truncated、032 ceil(B/4) 计量直接复用，无需新口径。

## 冲突与裁决

1. **SSRF 闸的位置**：考古（pi 方案）＝请求前校验＋每跳重校验；HTTP 专家指出两次解析间仍有 TOCTOU/rebinding 竞态，主张把闸装进 reqwest 自定义 `Resolve`（解析层只放行公网地址）。**裁决：解析层闸为准**（强于 pi），请求前校验与每跳校验保留为纵深。
2. **搜索首发后端**：考古（pi 默认）＝DuckDuckGo HTML 免密钥保底；搜索专家以官方 pricing 页证据主张 Tavily（1000 credits/月免信用卡）＋Brave（新用户每月 $5 额度）双密钥首发，DDG 验证码频发、`duckduckgo_search` crate 已停更，只配兜底。**裁决：双密钥首发，DDG 做可选兜底开关**，实现前先连发 100 次实测封禁率再定去留。
3. **审批面**：考古初稿建议接 031/033 策略；集成专家读码后指出 bwrap/031 只包 exec/MCP/补丁**子进程**，web 请求从宿主进程出网，硬接是假接线。**裁决：不进 031**；用域名白名单配置＋可信环境变量门控默认关，031 扩展留待有真实需求再做。
4. **抓取结果要不要加工**：社区最大骂点是 Claude Code WebFetch 暗藏小模型摘要导致内容失真；pi-web-access 的 `answer` 模式同类。**裁决：V1 只有 readable/raw 原文直给模型**，`answer`/`extract`/PDF/视频帧全部不做——规避失真骂点＋砍掉一半工作量。

## 社区校准（侦察兵简报）

- 「能用但别信」的口碑支持本方案的两个结构选择：原文直给（不做静默摘要）＋结构化报错（Cloudflare 403/503＋cf-mitigated 头即报错不硬闯，与社区"绕封锁有封号风险"的告诫一致）。
- Codex「默认旧缓存快照」的骂点提醒：文档必须写明 web_fetch 永远实时、web_search 走 live API，无快照语义。
- 「token 花销看不见」的骂点：本方案正文过 003 截断＋032 计量＋012 TUI 工具详情可见大小，盲区已有关键防線。

## 组合方案（按优先级）

1. **SSRF 闸**：自定义 `Resolve`（逐 IP 判公网，拒绝表含 0.0.0.0/8、100.64/10、169.254/16、64:ff9b::/96）＋url crate WHATWG 归一化＋IP 字面量补校验＋`redirect(Policy::none)` 手动 ≤5 跳逐跳过闸＋跳转不透传凭证头＋禁环境代理＋总墙钟 deadline。
2. **提取链**：readability-rs＋htmd＋chardetng；壳页检测（可见文本<500 字且 script>3，或 403/503＋cf-mitigated）报错。
3. **搜索**：Tavily＋Brave 双密钥后端（凭证走既有 key_ref 体系），契约对齐 Claude Code；DDG 兜底可选开关＋冷却退避。
4. **接线**：web_access.rs 单文件＋prompt.rs 两个 json! 定义（可信环境变量门控，默认关）＋turn.rs call.name 链分支（view_image 同款）＋tui_host 渲染分支；独立 ureq Agent（HTTPS-only、redirects(0)），不与 api.rs 共享实例。
5. **安全收口**：025 脱敏扩面到工具结果正文（sk-/ghp_ 形态正则，入史前执行）；内联截断复用 003＋30k 字符档；全文缓存＋翻页工具（get_search_content 等价物）视 V1 体量决定，可后置。
6. **验证**：Mozilla test-pages 130 例 golden 契约测试＋OWASP SSRF 矩阵实测＋mock HTTP 录制夹具（离线可复现）＋全量 `cargo check && cargo test --workspace --no-fail-fast`＋PTY e2e；DDG 兜底连发 100 次实测封禁率。

## 背景知识

- reqwest blocking 的 `timeout` 只限单次 IO，总时限必须自设墙钟 deadline——这是 Node AbortController（pi 的做法）到 Rust 的最大语义差。
- url crate 按 WHATWG 自动归一化十六进制/八进制 IP 字面量（`0x7f.1`→127.0.0.1），多数花式绕过被解析器直接消化；IPv6 zone id 解析即错，拒之即可。
- std `Ipv4Addr::is_global` 1.87 才稳定且留有缺口（100.64/10 等），只能做基线，拒绝 CIDR 表才是主判。
- Claude Code WebFetch 的「双会话」架构（副会话小模型按 prompt 加工网页）是社区失真吐槽的根源；「原文直给」即差异化。
- Brave 免费层规则已变（老 2000 次/月计划停新注册，新用户按每月 $5 额度计），实施时额度以注册当日官方页为准。
- 031/033 的射程是子进程；宿主自身出网是独立攻击面——「工具级开关＋域名白名单＋默认关」是本项目现阶段的正确边界，别假接 031。
