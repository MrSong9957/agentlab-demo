# 015 用户轮上下文注入——安全检查报告（轻量）

> 日期：2026-10-20　范围：`feat/015-turn-context-injection`（规格 `docs/specs/015-turn-context-injection.md`）
> 检查方式：新增自动文件读取面的逐项审查＋定向测试与运行时探针；无专用安全 Skill，按规格 §5 预案出轻量报告。

## 1. 新增攻击面

每个用户轮自动读取：`config_dir()/AGENTS.md`（`TCHAT_CONFIG_DIR` 可覆盖）＋「最近 `.git` 祖先→cwd」各目录的 `AGENTS.md`；读取结果作为 user 消息随模型请求外发。文件名固定（`AGENTS.md`），无用户可控路径拼接；目录来源与 002 配置机制同源（`catalog::config_dir`，`.env` 信任根跳过名单 F1 已覆盖 `TCHAT_CONFIG_DIR`）。

## 2. 检查项与证据

| 检查项 | 方法 | 结果 |
|---|---|---|
| 符号链接来源 | `symlink_metadata` 判定＋跳过；`t04`（symlink→notice，正文不入消息） | 通过 |
| 非普通文件（目录/FIFO/设备） | 同上；`t04`（目录→notice） | 通过 |
| 读取失败/非法 UTF-8 | 跳过＋原因提示、不中止轮；`t04`（chmod 000＋非法字节） | 通过 |
| 缺失/纯空白 | 静默跳过；`t02`/`t04` | 通过 |
| 读取预算（不整读） | 单文件读取上限＝剩余预算＋3（多字节边界判定）；**运行时探针**：200 MiB 全 `Z` 的 `AGENTS.md`，content 恰 32768 字节、截断提示存在、进程峰值 RSS（VmHWM）3628 KiB ≪ 204800 KiB——未整读（探针为临时测试，证据跑毕即删，非交付物） | 通过 |
| 正文总量上限 | 拼接（含分隔）≤32768 字节、UTF-8 字符边界回退；`t09`（两文件/多字节边界/恰好占满三态） | 通过 |
| 预算耗尽停止加载 | 耗尽后不再打开任何后续来源文件，仅以元数据判定是否提示；`t09c` | 通过 |
| 环境块转义 | cwd/SHELL 按 XML 文本转义（`&`/`<`/`>`），SHELL 缺失或纯空白整行省略；`t13`/`t02` | 通过 |
| 提示行内容 | 仅路径＋原因类别，不含规则正文；`t04` 断言提示不含正文片段 | 通过 |
| 记忆提炼输入兼容 | ctx 消息（裸/带声明）自提炼输入剔除，规则正文不作为用户事实进入长期记忆；`rollout_input::context_injection_messages_excluded_and_legacy_rules_kept`＋`memory_phase1::m3`（含声明形态样本） | 通过 |
| 空白输入副作用顺序 | 校验先于上下文写入，拒绝时历史/`on_record` 零新增；`t11` | 通过 |
| 展示层 | 注入不产生展示事件；TUI `/resume` 投影跳过 ctx（不当作用户发言）；`tui_host::project_history_items_skips_context_messages`＋e2e s10 类投影用例不变 | 通过 |
| 外发边界（已知同面） | AGENTS.md 内容随请求发给模型服务——与 Codex 及用户手动粘贴同面；本地文件由使用者控制，不做密钥扫描（规格 §2 边界记录） | 记录在案 |

## 3. 剩余限制

- 规则正文外发依赖用户对自身 AGENTS.md 的控制（与 003/005 既定姿态一致）；不新增缓解。
- 预算耗尽的「是否还有来源」判定只看元数据：以空白开头的后续普通文件也会触发提示（多报一角，不影响预算上界与读取严格性）。
- `.git` 标记可为符号链接（只影响链根选择，加载仍限普通非符号链接文件），无安全影响。

## 4. 结论

新增读取面满足：固定文件名、只读、有界、异常跳过不中止、提示不含正文、环境值转义、记忆输入剔除。未发现可利用问题；上述限制均已记录。
