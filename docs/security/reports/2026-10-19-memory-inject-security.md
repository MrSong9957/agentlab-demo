## 源码审查结论

读取入口显式接收记忆根/配置，M7 生产接线尚未实现；无隐式真实用户目录解析、数据库初始化、写文件或执行命令。两个开关先于文件读取。UTF-8 失败/空白跳过，按固定上游仅把摘要当文本读取，不自行增加版本首行策略。模板渲染只处理固定模板，不二次解释路径或摘要中的占位符。JSON 经 serde_json 组装，摘要不拼接为 JSON 语法或 shell。D4 仅在唯一 system 的尾段追加历史参考，不提供新工具。

轮快照是单次 turn 的局部值，不放入 HistoryItem；M3 提炼及 MemoryMerge 不走读取分支，合并轮仍只提供三项受限工具。主动工具读取记忆后产生的工具结果仍按原契约入史；禁止持久化的是程序自动注入块，不虚称所有记忆文字都不入史。

## 发现、限制与处置

- 本轮未发现新增可复现的安全缺陷；没有遗留的本轮高风险阻断项。
- **继承的读取资源边界**：上游先 read_to_string 全量读取再截断。2,500 tokens 限制保留正文，不是磁盘读取字节/内存硬上限；本轮未自行增加文件大小/FIFO/符号链接拒绝策略。记忆根可信来源及私有目录由 M1 约定，真实驱动接线归 M7。
- **模型语义未证明**：固定边界/历史参考说明不是对模型提示注入的强隔离证明；未经真实模型试发，不声称恶意文本一定被模型忽略，也不声称 system/developer 等价。供应商实测仍归 M7。
- Linux inotify 为本环境的额外 I/O 证据；Windows 未实测。V2、专用工具、后台管线与引用反馈均不在本轮。

本轮不改安全门禁源文件，不调用真实模型，不写真实会话或记忆目录。最终全量与静态检查结果见主实施记录。
