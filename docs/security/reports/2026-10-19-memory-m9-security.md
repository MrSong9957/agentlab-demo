## 审查与实测结果

| 风险面 | 实际方法、结果与适用限制 |
|---|---|
| 删除根外文件 | 在根、extensions、扩展、resources、资源文件各层布置指向临时外部目标的链接；独立扫描拒绝跟随，外部文件字节不变。管线原 layout 清链接仍由 M4 回归覆盖。未把既有合作式路径检查声称为 OS sandbox |
| 错删便条/原始会话 | 资源扫描仅 extensions 指定子树；notes、非法日期、非 md、子目录样本保留。单批及同链检查原始 A/B Session 字节不变，不访问真实用户目录 |
| SQL 条件/注入 | 固定上游 DELETE，cutoff/limit 通过参数绑定；仅未选中且窗口外结果可删。边界两侧/等号、NULL 回退、last_usage 优先、selected 保护以 SQL 状态核对；不拼接来源 ID 为 SQL，不暴露新 SQL 工具 |
| 大批删除/任务丢失 | 202 条分 200＋2、runner 201 条分 200＋1，limit 0；jobs/成功水位/threads 保留，清理后同版不重新提炼、新版本可处理。去保护或 200→201 变异实际失败 |
| reset 后旧任务删新代 | selection→sync 闸门中 reset，新代资源保留，旧任务按失效失败；模型等待中 reset 可在看门窗口内完成，旧响应不能重建库/Git/产物。移除 epoch 核对及模型等待持文件锁变异均被检出 |
| 清理错误扩大损失 | 非 root 临时 chmod 实际触发删除权限失败，告警继续其他扩展；临时 SQLite 触发器阻止 DELETE，runner 仍进入合并，下次解除故障可继续。NotFound 与非法名按上游跳过，无“全清成功”承诺 |
| 差异丢失/状态掩盖 | 真正资源/摘要删除进入实际 mem_read→模型工具续请求→mem_write→Git；提前 reset 和断清理/同步变异失败。保留上次 selected 至成功合并解除，之后下一批物理删行，既有非跨存储事务边界不变 |
| 配置泄漏/敏感输出 | 新清理不请求网络、不读凭证、不输出用户数据；告警经过显示净化。真实 rg 测试使用临时 HOME/XDG、env -i/--no-config，临时恶意配置不能改变输出，修复后的错误检测已实跑 |

新增两目标实际 **13通过/0失败/0忽略**；最终 `cargo check` exit 0、`cargo test --workspace --no-fail-fast` exit 0（3010/0/3），详见同一实施记录。全量首轮 S89/S90 独立夹具因不再满足保留前提而失败，修正为真实成功事务选中来源后原引用断言不变；不是放宽删除保护条件。
